# omniddi Provider

Manage DNS, DHCP and IPAM objects in OmniDDI. Every attribute except `default_tags` can also be set through an `OMNIDDI_*` environment variable; the attribute wins when both are present.

OmniDDI is a DNS, DHCP and IP address management (DDI) platform. Through the OmniDDI management server, the provider manages:

- DNS zones and records.
- IPAM containers and subnets, including a subnet placed in the next free block of a container.
- IP addresses allocated as the next free address in a subnet.
- DHCP subnets and host reservations.

Data sources read DNS views and zones, network spaces, server groups and the IP space tree, and show the next free addresses or blocks without allocating them.

## Authentication

The provider signs in with the `username` and `password` of an OmniDDI account and works with that account's roles. Use a dedicated automation account without MFA, and pass the password through `OMNIDDI_PASSWORD`. Set `network_space_id` to work in a network space other than the account's landing space. See the [authentication guide](guides/authentication.md) for the recommended account setup.

## Environment variables

Every attribute except `default_tags` can be set from the environment. The attribute wins when both are present.

| Attribute | Environment variable |
|---|---|
| `endpoint` | `OMNIDDI_ENDPOINT` |
| `username` | `OMNIDDI_USERNAME` |
| `password` | `OMNIDDI_PASSWORD` |
| `network_space_id` | `OMNIDDI_NETWORK_SPACE_ID` |
| `ca_cert_pem` | `OMNIDDI_CA_CERT_PEM` |
| `client_cert_pem` | `OMNIDDI_CLIENT_CERT_PEM` |
| `client_key_pem` | `OMNIDDI_CLIENT_KEY_PEM` |
| `proxy_url` | `OMNIDDI_PROXY_URL` |
| `insecure` | `OMNIDDI_INSECURE` |
| `timeout` | `OMNIDDI_TIMEOUT` |
| `approval_mode` | `OMNIDDI_APPROVAL_MODE` |
| `max_concurrency` | `OMNIDDI_MAX_CONCURRENCY` |
| `max_retries` | `OMNIDDI_MAX_RETRIES` |

## TLS, proxy and mutual TLS

- `ca_cert_pem` adds a private CA to the trusted roots.
- `client_cert_pem` and `client_key_pem` enable mutual TLS and must be set together.
- `proxy_url` sets an HTTP proxy. When it is unset, the standard `HTTPS_PROXY` and `NO_PROXY` variables are honored.
- `insecure = true` skips certificate verification and prints a warning on every run. Use it for development only.

## Example usage

```terraform
terraform {
  required_providers {
    omniddi = {
      source = "checkred/omniddi"
    }
  }
}

provider "omniddi" {
  endpoint = "https://omniddi.example.com"
  username = "terraform-automation@example.com"
  # Set the password through the OMNIDDI_PASSWORD environment variable.

  # Omit to work in the account's landing network space.
  network_space_id = 2

  approval_mode = "fail"

  default_tags = {
    "Managed-By" = "terraform"
  }
}
```
